📺 레오: 작업 시작합니다.

사장님, 현재 **YouTube Data API 키**와 **채널 ID**가 없으므로 아래 정보를 입력해 주시면 바로 채널 메타데이터(구독자 수, 평균 조회수, 시청 지속률 등)를 한 번에 가져오는 스크립트를 실행하겠습니다.  
필요한 값은 다음 두 가지입니다:

1. **YOUTUBE_API_KEY** – YouTube Data API v3 인증키  
2. **YOUTUBE_CHANNEL_ID** – 본 채널의 고유 ID (예: `UCxxxxxxxxxxxx`)

> 📊 채널 분석을 하려면 YouTube API 키와 채널 ID가 필요해요. 헤더 우측 "👥 직원 에이전트 보기" 버튼 → YouTube 카드 ⚙️ 클릭 → API 키와 채널 ID 입력 후 다시 요청해주세요.
