# 📝 CEO 종합 보고서

📺 레오: 작업 시작합니다.

사장님, 현재 유튜브 채널 데이터를 수집하려면 **YOUTUBE_API_KEY**와 **YOUTUBE_CHANNEL_ID**가 필요합니다. 아래 양식을 사용해 입력해 주세요. 입력이 완료되면 자동으로 최근 30일 영상 조회수, 평균 시청시간(분), CTR을 가져와 `channel_analytics.json` 파일에 저장하도록 하겠습니다.

---

### ✅ 입력 양식

| 항목 | 예시 | 비고 |
|------|-------|------|
| **YOUTUBE_API_KEY** | `AIzaSyD...` | API 콘솔에서 발급받은 키 |
| **YOUTUBE_CHANNEL_ID** | `UC1234567890abcdef` | 채널의 고유 ID (URL 끝부분) |

> 입력 예시  
> ```
> YOUTUBE_API_KEY=AIzaSyD...
> YOUTUBE_CHANNEL_ID=UC1234567890abcdef
> ```

### 📌 다음 단계

1. **위 정보를 복사**해 `~/.config/youtube_account.json`에 저장하거나, 아래 스크립트를 실행할 때 바로 입력합니다.

> ⚠️ **API 키/채널 ID가 없으면** 데이터 수집은 불가능합니다. 반드시 제공해 주세요.
