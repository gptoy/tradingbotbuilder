📺 레오: 작업 시작합니다.

## 현재 상황
- **YouTube Data API 키** 및 **채널 ID**가 아직 설정되지 않았습니다.  
- `youtube_account.py`를 실행해 인증 정보를 입력해야 모든 YouTube 도구(업로드, 분석 등)가 동작합니다.
- 테스트용 비디오 파일이 준비되어 있지 않으며, 업로드 스크립트(`upload_video.py` 등)의 경로가 명시되지 않았습니다.

## 가장 가치 있는 단일 작업
1. **YouTube 인증 설정** → API 키와 채널 ID를 `youtube_account.json`에 입력하고, `youtube_account.py` 실행.
2. **업로드 스크립트 사용법 문서화** → 비디오 파일 경로, 제목, 설명, 태그 리스트 4개의 매개변수를 명시한 Markdown 가이드 작성.
3. **테스트용 샘플 비디오 업로드** → `upload_video.py`(예: `c:\Users\user\.connect-ai-brain\_company_agents\youtube\tools\upload_video.py`)를 실행해 결과 확인.

이 세 단계가 가장 빠른 진행 경로이며, 인증 없이는 업로드 자체가 불가능하므로 먼저 설정을 완료해야 합니다.
