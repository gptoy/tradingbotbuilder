### 스케치 예시

```
+-------------------------------------------+
| [초간단 스케일업]                        |
|                                           |
|   [책상 정리 전 이미지]   [조명 교체 후 이미지]|
```

- **폰트**: Montserrat (Google Fonts)
- **텍스트 대비**: 배경은 짙은 차콜이므로 흰색과 노란색 텍스트가 뚜렷함
- **이미지 비율**: 1080×1920 (IG 릴스) → 상단 40% 이미지, 하단 60% 텍스트

> **Tip**: 이미지 편집 시 `Photoshop` 또는 `Affinity Photo`에서 레이어를 활용해 각 요소를 개별 조정하세요.
