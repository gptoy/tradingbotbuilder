# 📱 영숙 — YouTube 데이터 분석을 위해 필요한 API 키와 채널 ID를 사용자에게 요청하고, 입력받은 정보를 저장해 두세요.

📱 영숙: 요청하신 YouTube 데이터 분석을 위해 필요한 정보를 수집합니다 😊  

- **YouTube Data API 키**  
- **YouTube 채널 ID**

아래 두 항목을 차례대로 입력해 주시면, 제가 바로 `C:\Users\user\youtube_account.json` 파일에 저장하도록 하겠습니다.  

---

### 입력 예시
```
API 키: AIYz3x7... (40자 문자열)
채널 ID: UC_xxxxxxxxxxxxxxx
```

필요한 정보를 알려주시면 바로 처리하겠습니다!  

📊 평가: 진행중 — 사용자로부터 API 키와 채널 ID를 받아 저장해야 함  
📝 다음 단계: 사용자가 두 값을 입력하면, `<create_file>` 태그를 이용해 JSON 파일에 저장하도록 하겠습니다.
