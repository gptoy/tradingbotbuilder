# 🎨 브랜드 로고 & 색상 팔레트 업그레이드 제안서

## 목표
- **시각적 일관성**: 기존 브랜드 톤과 맞춰 현대적이면서도 차별화된 비주얼  
- **확장성**: 모바일, 웹, 오프라인 매체 모두에 적용 가능한 로고 & 팔레트  

## 1. 로고 리디자인 컨셉
| 요소 | 설명 |
|------|------|
| **심볼** | ‘기환’의 이니셜 G와 H를 결합한 추상적 모노그램. 라인 스타일은 둥글면서도 직선적, 균형감 제공 |
| **타이포그래피** | `Montserrat ExtraBold` (가독성 + 현대미) → 메인 로고 텍스트로 사용 |
| **배치** | 심볼 좌측, ‘김기환’ 우측. 가변 폭 로고는 심볼만으로도 독립 가능 |

### 2. 색상 팔레트
| 컬러명 | HEX | RGB | 사용 예시 |
|--------|-----|-----|-----------|
| **메인 블루** | #0A3D62 | rgb(10,61,98) | 로고 심볼, 헤더 배경 |
| **오렌지 보조** | #FF9F1C | rgb(255,159,28) | CTA 버튼, 강조 텍스트 |
| **라이트 그레이** | #E0E4E8 | rgb(224,228,232) | 배경 색상, 카드 베이스 |
| **다크 네이비** | #061B32 | rgb(6,27,50) | 폰트 색 (헤더) |
| **화이트** | #FFFFFF | rgb(255,255,255) | 텍스트 대비 |

> **컬러 사용 가이드**  
> - 로고는 메인 블루 + 화이트 조합으로 최적화.  
> - 배경은 라이트 그레이 기반에 다크 네이비 포인트 활용.  

## 3. 적용 예시
- **웹사이트 헤더**: 메인 블루 배경, 로고 좌측 상단, 네비게이션 텍스트는 화이트.
- **SNS 배너**: 오렌지 보조를 활용한 CTA 버튼, 라이트 그레이 배경에 로고.

## 4. 전달물
| 파일 | 용도 |
|------|------|
| `logo.svg` | 벡터 로고 (웹·프린트) |
| `palette.pdf` | 색상 코드 및 예시 이미지 |

### 2️⃣ YouTube 썸네일 템플릿

- **해상도**: 1280x720 px
- **배경**: 메인 블루 그라데이션(좌우 #0A3D62 → #061B32)
- **타이포그래피**:
  - 타이틀: `Montserrat ExtraBold`, 70px, 화이트
  - 서브타이틀: `Montserrat Regular`, 40px, 오렌지 보조 (#FF9F1C)
- **이미지 영역**: 중앙에 큰 비주얼(예: 그래프 또는 인물 사진) 배치
- **CTA**: 우측 하단 ‘▶️ 지금 시청’ 버튼 (오렌지 보조 + 흰색 글자)

> 파일은 PNG 형식으로 저장하며, 텍스트 레이어는 별도 PSD 파일에 포함.
