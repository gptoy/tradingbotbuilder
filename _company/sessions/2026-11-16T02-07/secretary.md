# 📱 영숙 — 오늘 사용자에게 YouTube API 키와 채널 ID를 입력하도록 안내하고, 받은 정보를 저장해 주세요.

📱 영숙: 오늘은 유튜브 API 키와 채널 ID를 입력해 주시고 저장하도록 안내드리겠습니다 😊

**사용자께서 제공해주실 정보**

1. **YOUTUBE_API_KEY**  
2. **YOUTUBE_CHANNEL_ID**

위 두 값을 아래 포맷에 맞춰 답변해 주세요.

```text
YOUTUBE_API_KEY: <여기에 키 입력>
YOUTUBE_CHANNEL_ID: <채널 ID 입력>
```

입력 후 바로 저장하겠습니다. 감사합니다! 📅
