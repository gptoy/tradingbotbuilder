### 1️⃣ 신규 구독 서비스

| 단계 | 액션 | KPI | 타임라인 |
|------|------|-----|-----------|
| **① 시장 조사** | 기존 유튜브/인스타 수익 모델 파악 + 경쟁사(예: “크리에이터 마켓”, “프리미엄 비디오”) 분석 | - 3개 주요 경쟁사의 가격·특징 표<br>- 사용자 여정 맵 | 2026‑11‑18 |
| **② 서비스 설계** | 구독 등급(무료, 베이직, 프리미엄) 정의 + 혜택 목록화 | - 등급별 혜택 명세서 (최소 8개 항목)<br>- 예상 월구독자 수 예측 (10%, 30%, 60%) | 2026‑11‑22 |
| **③ 가격 전략** | 가치 기반 가격 모델 도출 + A/B 테스트 계획 수립 | - 제안 가격대(3개)와 예상 ARPU<br>- A/B 테스트 전후 구독자 전환율 변동 | 2026‑12‑01 |
| **④ 플랫폼 구축** | Patreon / Ko-fi 연동, 멤버십 페이지 디자인 | - 통합 결제 시스템 구현 여부<br>- UI/UX 테스트 완료 시점 | 2027‑01‑05 |
| **⑤ 론칭 & 마케팅** | 프리미엄 콘텐츠 티저 + 인플루언서 콜라보 | - 초기 가입자 목표(100명)<br>- SNS 홍보 도달 수치 50,000+ | 2027‑02‑10 |

#### KPI 세부

| KPI | 정의 | 월 기준 |
|-----|------|--------|
| **ARPU** | 평균 월 구독료 | ≥ $8.00 |
| **구독자 전환율** | 무료 → 유료 비율 | ≥ 3% |
| **이탈률(Churn)** | 구독 해지 비율 | ≤ 5% |
| **고객 평점** | NPS(순추천지수) | ≥ +50 |

| 단계 | 액션 | KPI | 타임라인 |
|------|------|-----|-----------|
