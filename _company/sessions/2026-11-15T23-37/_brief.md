# 📋 작업 브리프

**원 명령:** [자율 사이클 — 2026-11-15] 1인 기업 24시간 운영 중. 회사 목표·각 에이전트의 개인 목표(_agents/{id}/goal.md)·최근 의사결정·메모리를 검토해서 지금 가장 가치 있는 단일 작업 1개를 결정하고, 적절한 1~2명 에이전트에게 분배해서 실행하세요. 같은 산출물을 반복하지 마세요 — 메모리에 비슷한 항목이 24시간 내에 있으면 다른 각도로 진전시키세요.

## 요약
지난 24시간 이내에 진행되지 않은 가장 가치 있는 작업은 유튜브 채널의 최근 30일간 조회수, 평균 시청시간(분), CTR을 수집해 JSON 파일로 저장하는 것이다.

## 분배
- **📺 레오**: YouTube Data API를 사용하여 지난 30일 동안 모든 영상의 조회수, 평균 시청시간(분) 및 CTR 데이터를 가져와 channel_analytics.json에 저장하라. API 키와 채널 ID는 이미 보유하고 있다. JSON은 배열 형태로 각 비디오별 {videoId, title, views, avgWatchTime, ctr} 항목을 포함하도록 구성한다.
