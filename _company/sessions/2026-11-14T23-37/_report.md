### 1️⃣ 파일 구조
```

```

### 2️⃣ 마크다운 본문 (`guide.md`)

```markdown
# 김기환 브랜드 시각적 가이드라인

## 1. 로고 사용 규칙
| 요소 | 규정 |
|------|------|
| **배치** | 인스타그램 피드: 왼쪽 상단, 릴스 썸네일: 중앙, 유튜브 미리보기: 왼쪽 하단 |
| **비율** | 최소 10%의 화면 비율을 차지해야 함. 예) 가로 1080px × 세로 1920px 인 경우 로고 가로 108px 이상 |
| **투명도** | 배경이 어두운 영역에서는 투명도 80% 이하 사용, 밝은 영역에서는 100% |

> **Tip**: 모든 로고 파일은 SVG와 PNG(300dpi) 두 가지 형식으로 제공됩니다.

## 2. 색상 팔레트
| 색상 | HEX | RGB | 용도 |
|------|-----|-----|------|
| 메인 블루 | #1B4F72 | (27,79,114) | 배경, 헤더, CTA 버튼 |
| 강조 오렌지 | #FF7E00 | (255,126,0) | 포인트 텍스트, 스포트라이트 |
| 중립 그레이 | #A3AEB5 | (163,174,181) | 서브텍스트, 배경 보조색 |

### 대비 체크리스트
- **배경 대비** : 텍스트 색상은 최소 4.5:1 대비 비율을 충족해야 함.
- **아이콘 대비** : 아이콘과 배경 사이에 최소 3:1 대비를 확보.

## 3. 타이포그래피

| 요소 | 폰트 | 두께 | 크기(픽셀) | 용도 |
|------|-----|------|-----------|------|
| 헤더 | Montserrat SemiBold (600) | 18-24 | 제목, 카테고리 |
| 본문 | OpenSans Regular (400) | 14-16 | 설명 텍스트 |
| CTA | Montserrat ExtraBold (800) | 20-28 | 버튼, 강조 문구 |

> **규칙**  
> - 인스타그램 피드: 텍스트 최대 가로 80% 사용.  
> - 릴스 썸네일: 메인 타이틀은 최소 48px, 부제는 32px.  
> - 유튜브 미리보기: 제목은 60px 이하, 부제는 36px 이하.

## 4. 레이아웃 가이드

| 플랫폼 | 해상도 | 주요 영역 | 비율 |
|--------|--------|-----------|------|
| 인스타그램 피드 | 1080×1080 | 이미지/비디오 + 텍스트 오버레이 | 60% 이미지, 40% 텍스트 |
| 릴스 썸네일 | 1080×1920 | 배경 + 타이포그래피 | 70% 배경, 30% 텍스트 |
| 유튜브 미리보기 | 1280×720 | 배경 + 로고 + 타이포 | 60% 이미지, 40% 텍스트 |

> **배경 대비**: 배경 색상이 밝은 경우에는 어두운 텍스트를 사용하고, 그 반대도 동일하게 적용.

## 5. 예시

| 플랫폼 | 예시 파일 |
|--------|-----------|
| 인스타그램 피드 | `feed_example.png` |
| 릴스 썸네일 | `reels_example.png` |
| 유튜브 미리보기 | `youtube_preview_example.png` |

> 각 예시는 3가지 색상 조합(블루-오렌지, 블루-그레이, 오렌지-그레이) 중 하나를 적용한 버전으로 제공됩니다.

## 6. 파일 저장 규칙

| 항목 | 형식 |
|------|------|
| 로고 | SVG (원본), PNG (300dpi) |
| 배경 이미지 | JPEG (최대 2MB, 300dpi) |
| 템플릿 | PSD (레이어 분리) |
| 최종 가이드라인 | PDF (210×297mm, A4) |

> **보안**: 모든 파일은 내부 네트워크에만 저장되며 외부 공유 시 암호화 필요.

```
