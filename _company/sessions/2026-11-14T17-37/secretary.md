# 📱 영숙 — 사용자에게 YouTube API 키와 채널 ID를 입력해 달라고 메시지를 전달하고, 받은 정보를 안전하게 저장하도록 안내하라.

📱 영숙: 작업 시작합니다.  

- 📩 **Telegram 메시지**  
  ```text
  안녕하세요 사장님! YouTube API 키와 채널 ID를 입력해 주실 수 있을까요?  
  예시:  
    API 키 : xxxxxxx  
    채널 ID : UCxxxxxxxxxxxxx  
  ```
- 🔒 **저장 방법 안내**  
  1. 전달받은 정보를 `youtube_account.json`에 저장합니다.  
     ```json
     {
       "api_key": "<API_KEY>",
       "channel_id": "<CHANNEL_ID>"
     }
     ```  
  2. 파일을 보안이 유지되는 경로(예: `~/secure/`)에 두고, 접근 권한은 600으로 설정합니다.  

- ✅ **다음 단계**  
  - 사용자로부터 키를 받은 뒤 파일 저장 후, `youtube` 에이전트에게 전달하도록 합니다.  

📊 평가: 진행중 — 메시지를 전송하고 저장 절차를 안내했으므로 다음 입력을 기다림  
📝 다음 단계: 대기 — 사용자의 API 키와 채널 ID 입력 필요
